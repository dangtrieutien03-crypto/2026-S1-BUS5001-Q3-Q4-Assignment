# ESG-LLM-Triage-Assignment

## Overview

This repository contains the experiment logs, evidence, prompts, outputs, and supporting materials developed for Assessment 3.

The assessment investigates the application of Large Language Models (LLMs) and cloud-based AI tools for Environmental, Social and Governance (ESG) related tasks.

The repository is organised into two sections:

* **Q3 - ESG Message Classification using LLMs**
* **Q4 - Evaluation of NotebookLM as a Cloud-Based Academic Assistant**

---

## Q3 – ESG Message Classification using LLMs

### Objective

To design and evaluate an improved prompt capable of classifying ESG-related operational messages into structured JSON outputs.

### Contents

* Improved prompt design
* Example ESG incident inputs
* JSON classification outputs
* Experiment evidence and screenshots

### Files

* `Improved_Prompt.txt`
* `Water_Leak_Output.json`
* `Recycling_Output.json`
* `Accessibility_Output.json`

### Example Scenarios

* Water leak in Building C
* Recycling contamination issue
* Blocked accessibility entrance

### Outcome

The revised prompt successfully generated structured ESG classifications including issue category, urgency level, recommended team, escalation reason, confidence score, and summary information.

---

## Q4 – Evaluating Cloud-Based Technology (NotebookLM)

### Objective

To evaluate the suitability of NotebookLM for academic and ESG-related analytical activities within a university environment.

### Source Document

PwC Slovakia Sustainability Report 2024

### Activities Performed

1. Upload sustainability report into NotebookLM
2. Generate document summaries
3. Analyse ESG risks
4. Create university-focused ESG briefings
5. Generate structured briefing reports
6. Produce sustainability infographics

### Evidence Included

* Report upload and source management
* Automated report summarisation
* ESG risk analysis
* University ESG briefing generation
* Sustainability briefing report generation
* Sustainability infographic generation

### Outcome

NotebookLM demonstrated strong capabilities in document-based question answering, summarisation, analytical reasoning, report generation, and content transformation. These features support academic workflows such as policy analysis, research preparation, sustainability reporting, and decision support.
